# 河牌手记产品规格 · R1 / Android 3.0

本规格描述当前实现。两名玩家使用一副 52 张牌，各持两张底牌，摊牌时以可用牌中的最佳五张比较牌力。产品提供权益复盘和限定下注树的河牌策略研究，两项计算均在本机执行。

## 权益分析

| 模式 | 输入 | 方法与输出 |
| --- | --- | --- |
| 翻前固定手牌 | 双方各两张不同底牌 | Monte Carlo 抽样五张公共牌，输出胜、平、负概率和权益 |
| 翻牌范围 | 自己两张牌、三张公共牌、对手范围 | 对每个合法组合抽样转牌和河牌，输出组合与汇总概率 |
| 转牌范围 | 自己两张牌、四张公共牌、对手范围 | 每个组合枚举 44 张河牌，输出终局胜平负计数及概率。全范围共 1,035 组、45,540 个终局 |
| 河牌范围 | 自己两张牌、五张公共牌、对手范围 | 逐组合摊牌。全范围共 990 组，每组结果为胜、平或负 |

范围可取全部合法组合等权，或逐项给出具体花色的两张牌和 0 至 1 的相对权重。重复组合（含反序）报错；零权重以及与自己手牌或公共牌冲突的组合在计算前排除。若没有可用组合则提示修正。各组合的最终概率按有效权重归一化汇总。自己的底池权益为独赢率加一半平局率。

「当前关系」按已发出的公共牌比较牌力。「最低权益」按该组合最终摊牌时自己的权益筛选。两个条件均只影响明细。对相同手牌和公共牌，仅调整范围权重可复用已完成的转牌组合计数。取消任务后不发布部分结果，过期任务的回调不能覆盖新任务。

## 河牌策略

模型输入为五张公共牌、OOP/IP 加权具体组合、根底池、双方剩余筹码和允许的首注及加注金额。双方私牌与公共牌必须构成合法发牌。求解器在给定行动树上运行 simultaneous CFR，输出平均策略。独立评估器计算最佳响应、可利用度及相对根底池误差。目标为相对误差 ≤ 0.1%，页面同时提供实际误差、迭代次数、双方根 EV 及各节点的组合行动频率和 EV。用户可设置迭代数和时限，或暂停后从匹配局面与算法版本的检查点续算。

## 运行与持久化

桌面由静态 HTML 和 JavaScript 运行。权益与策略使用各自的后台计算入口。Android 包名为 `org.rivernotes.poker`，R1 的 versionCode 为 3，最低 API 28，目标 API 35。Android WebView 加载包内资源。手动保存的局面保存在浏览器本地存储或 Android 历史数据库，命名范围按名称更新，载入后按当前已知牌重新处理阻挡。
