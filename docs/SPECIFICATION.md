# GTO训练营 v6 产品规格

本规格描述当前实现。桌面离线版与 Android 6.0 共用范围表和计算引擎。翻前建议使用 6 人现金桌、100 BB 有效筹码、无前注和无 straddle 的模型。权益与河牌策略使用单挑模型，双方各持两张底牌，摊牌时用最佳五张比较牌力。所有功能均可离线运行。

## 翻前建议

教学范围表 1.0.0 覆盖开池 5 个局面、面对单人开池 15 个局面、开池后面对 3-bet 15 个局面。每个局面有 169 类起手牌。开池尺度为 2.5BB，小盲为 3BB。有位置和无位置的 3-bet 分别加到开池额的 3 倍和 4 倍，4-bet 分别加到 3-bet 额的 2.2 倍和 2.5 倍。大盲对小盲时翻后有位置。

范围表由项目编写，高频与低频表示定性教学分档。合法行动按局面显示，每手牌拥有一个高频首选，部分手牌另有低频备选。「高亮行动」和「频率」只改变矩阵显示。若某手牌在该位置从不开池，则开池后面对 3-bet 的局面标为未开池。可通过矩阵和下拉框查询同一份范围表。

## 训练与位置对照

训练、查表及错题复盘使用同一份 `getSpot()`、`recommend()` 与行动解释。标准轮次为 10 手，混合模式涵盖三种翻前决策，也可限定到单个位置局面。每轮按局面与手牌去重，只选择当前行动线可达的牌。反馈按高频、低频、不建议分档，只有不建议的答案进入错题本。错题按局面和手牌去重。错题复练最多取 10 手，可按局面筛选；复练时选择高频或低频动作即移出该题。当前轮次、答题进度和错题在设备本地保存。

面对开池或 3-bet 并且存在两个合法对手位置时，位置对照固定手牌与自己的位置，显示两侧的行动线、金额、首选与理由。工作台、翻前查询和答题独立于权益、河牌计算任务。

## 权益分析

| 模式 | 输入 | 方法与输出 |
| --- | --- | --- |
| 翻前固定手牌 | 双方各两张不同底牌 | Monte Carlo 抽样五张公共牌，输出胜、平、负概率和权益 |
| 翻牌范围 | 自己两张牌、三张公共牌、对手范围 | 对每个合法组合抽样转牌和河牌，输出组合与汇总概率 |
| 转牌范围 | 自己两张牌、四张公共牌、对手范围 | 每个组合枚举 44 张河牌，输出终局胜平负计数及概率。全范围共 1,035 组、45,540 个终局 |
| 河牌范围 | 自己两张牌、五张公共牌、对手范围 | 逐组合摊牌。全范围共 990 组，每组结果为胜、平或负 |

范围可取全部合法组合等权，或逐项给出具体花色的两张牌和 0 至 1 的相对权重。重复组合（含反序）报错；零权重以及与自己手牌或公共牌冲突的组合在计算前排除。若没有可用组合则提示修正。各组合的最终概率按有效权重归一化汇总。自己的底池权益为独赢率加一半平局率。

「当前关系」按已发出的公共牌比较牌力。「最低权益」按该组合最终摊牌时自己的权益筛选。两个条件均只影响明细。对相同手牌和公共牌，仅调整范围权重可复用已完成的转牌组合计数。取消任务后不发布部分结果，过期任务的回调不能覆盖新任务。

## 河牌策略

模型输入为五张公共牌、OOP/IP 加权具体组合、根底池、双方剩余筹码和允许的首注及加注金额。双方私牌与公共牌必须构成合法发牌。求解器在给定行动树上运行 simultaneous CFR，输出平均策略。独立评估器计算最佳响应、可利用度及相对根底池误差。目标为相对误差 ≤ 0.1%，页面同时提供实际误差、迭代次数、双方根 EV 及各节点的组合行动频率和 EV。用户可设置迭代数和时限，或暂停后从匹配局面与算法版本的检查点续算。

选牌弹窗在桌面与手机均固定为四行十三列。牌码中的 T 显示为 10，存储继续使用原有两字符牌码。

河牌解读按所选具体手牌、已知公共牌、双方范围权重和行动历史推算对手组合的条件概率。跟注打平门槛为本次需补的筹码除以跟注后总底池；平局计半份权益。动作比较使用同一手牌、同一节点的行动 EV 差额。对手回应按所选投入金额及解出的策略计算，按该回应内部的条件权重展示更强、打平和更弱的牌，每类最多列出占比最高的三个具体组合。零到达的手牌或分支不展示条件数值。整体行动频率按各手牌到达节点的概率加权。

## 运行与持久化

桌面由静态 HTML 和 JavaScript 运行。权益与河牌策略使用各自的后台计算入口。Android 包名为 `org.rivernotes.poker`，6.0 的 versionCode 为 6，最低 API 28，目标 API 35。Android WebView 加载包内资源。手动保存的局面保存在浏览器本地存储或 Android 历史数据库，命名范围按名称更新，载入后按当前已知牌重新处理阻挡。
