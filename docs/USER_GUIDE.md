# 河牌手记用户指南

## 安装与打开

电脑上解压完整项目，用 Chrome 或 Edge 打开根目录的 `index.html`。请保留目录结构；再次查看历史时，使用相同的浏览器和文件位置。要研究河牌下注，直接打开 `strategy/index.html`。

按 [README 中的 Android 构建步骤](../README.md#开发验证)生成 3.0 安装包，将其复制到手机，打开并按系统提示安装。自行构建的 APK 使用本地签名，覆盖安装要求签名一致。卸载应用或清除应用存储会删除本地记录。

## 第一次复盘：转牌上的 AA

1. 在首页选择「翻后范围」。点击「我的手牌」牌位，选入 A♠、A♥。依次选入公共牌 K♣、7♦、2♥、3♠。选错时点击已有牌位即可替换或移除。
2. 将「对手范围」切换为「自定义加权组合」。录入 K♦ K♥，权重填 0.75，再录入 Q♣ Q♦，权重填 0.25。列表中只保留这两组。
3. 点击「开始计算」。面对三条 K，你在 44 张可能的河牌中赢 2 次；面对一对 Q，你赢 42 次。两组均无平局，加权后的底池权益为 **27.27%**。
4. 在「当前关系」选择「我落后」，列表只显示三条 K 那一行。顶部仍显示整个输入范围的结果。点击「保存局面」，之后可以从右上角「历史记录」恢复。

若要重复使用对手范围，填写「范围名称」并点「保存范围」。同名保存会更新配置。「载入已保存的范围」可在其他局面复用，计算时会按新的手牌与公共牌排除冲突组合。

## 选哪种分析

- 已知两人的翻前手牌时，选「翻前全下」，各输入两张牌。结果按模拟发完五张公共牌估算。「交换手牌」可切换观察方。
- 已知公共牌时，选「翻后范围」。默认给所有合法对手手牌相同权重。三张公共牌时模拟后续发牌；四张时穷举河牌；五张时直接摊牌。
- 「独赢率」只计自己获胜的机会。「底池权益」把平局按半个底池计入。例如公共牌已经组成皇家同花顺时，双方打平，自己的权益为 50%。
- 计算中可点「取消计算」，改好输入后重新开始。Android 切到后台会停止活动计算，返回后可重算。需要下次打开时恢复结果，请先点「保存局面」。

## 研究河牌下注

1. 打开河牌策略页，在「载入基准」选择「小范围 · 等权」或「小范围 · 非等权」。OOP 先行动，IP 后行动。
2. 首次可直接点「开始牌局求解」。自定义时，选好五张公共牌，在「编辑双方范围与下注尺度」中设定手牌、权重和筹码金额。例如首注填 `50`、加注填 `50:100`，表示面对 50 的首注可以加到总额 100。
3. 在「求解状态」查看实测可利用度占根底池的比例。目标为 0.1% 或更低；若先耗尽预算，结合实际误差阅读结果。要分次运行，可点「暂停并保存」，再从检查点继续。
4. 选择「公共行动历史」，在行动方矩阵里选牌类，再选具体组合，查看该节点各动作的频率和 EV。EV 以筹码计量，起算点是河牌根节点。改变范围或下注尺度后需重新求解。
