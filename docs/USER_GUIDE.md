# GTO训练营 v6 用户手册

## 安装与打开

在 GitHub 仓库点 **Code → Download ZIP**，解压后用 Chrome 或 Edge 打开项目根目录的 `index.html`。如果拿到的是已打包的桌面离线 ZIP，也可以这样打开。保留目录结构，再次查看历史时使用相同的浏览器与文件位置。

按 [README 的构建说明](../README.md#测试与构建)生成 v6 APK，复制到手机后点开安装。已安装 v5 且新包使用原签名时可直接覆盖升级，安装后在桌面找到「GTO训练营」。卸载应用或清除应用存储会删除本地记录。

## 开始训练

在训练工作台点「开始训练」，每轮 10 手。先读座位、手牌和行动线，再点弃牌、跟注或带总金额的加注按钮。答题后可看理由，点「下一手」继续。离开后从首页的「继续训练」返回同一轮。

「低频可选」单独计数。选择「不建议」的行动时，该题会进入错题本。可从首页的「错题本」按局面复习，也可以在答题后点「查看范围」，再返回原题。点「复练错题」时每轮最多抽 10 手；复练中选中高频首选或低频备选，该题就会移出错题本。

## 查看翻前建议

1. 从首页进入「查翻前范围」。选择此前行动和自己的位置，遇到加注时再选开池者或 3-bet 者的位置。页面显示双方的筹码投入和轮到谁行动。
2. 点矩阵里的牌、在「快速查牌」输入 `99`、`A5s`、`AKo`，或在「所选手牌」下拉框选择。矩阵上方的摘要会随选择更新。对角线是对子，上方的 `s` 代表同花，下方的 `o` 代表不同花。详情列出高频首选、低频备选、加到多少 BB 和理由。
3. 在「高亮行动」选择 3-bet 或 4-bet，再按高频或低频筛选。局面有两个以上合法对手时，在「位置对照」选择另一位置，两侧均可进入对应的练习。BB 表示一个大盲注；按钮上的「加到」表示加注后的总投入。例如 BTN 持 `99` 面对 UTG 开池时首选跟注，面对 CO 开池时首选 3-bet。面对 3-bet 时，开池表里始终弃牌的起手牌标为「未开池」。

范围表 1.0.0 采用 6 人现金桌、100BB 有效筹码及固定加注尺度。高频表示教学首选，低频表示可混合的备选。范围表由本项目编写，参考位置、盲位防守和再加注的教学原则。[六人桌策略](https://upswingpoker.com/6-handed-max-poker-strategy/) · [再加注原则](https://upswingpoker.com/re-raising-poker-when-how-much/) · [口袋 99 案例](https://upswingpoker.com/pocket-nines-cash-games/)

## 输入具体手牌

手牌、公共牌和加权组合共用四行选牌布局。四行依次为 ♠、♥、♣、♦，每行从 A 到 2。相同点数上下对齐；灰色牌位表示该牌已被占用。

## 第一次复盘：转牌上的 AA

1. 从工作台进入「权益复盘」，再选择「翻后范围」。点击「我的手牌」牌位，选入 A♠、A♥。依次选入公共牌 K♣、7♦、2♥、3♠。选错时点击已有牌位即可替换或移除。
2. 将「对手范围」切换为「自定义加权组合」。录入 K♦ K♥，权重填 0.75，再录入 Q♣ Q♦，权重填 0.25。列表中只保留这两组。
3. 点击「开始计算」。面对三条 K，你在 44 张可能的河牌中赢 2 次；面对一对 Q，你赢 42 次。两组均无平局，加权后的底池权益为 **27.27%**。
4. 在「当前关系」选择「我落后」，列表只显示三条 K 那一行。顶部仍显示整个输入范围的结果。点击「保存局面」，之后可以从右上角「历史记录」恢复。

若要重复使用对手范围，填写「范围名称」并点「保存范围」。同名保存会更新配置。「载入已保存的范围」可在其他局面复用，计算时会按新的手牌与公共牌排除冲突组合。

## 选哪种分析

- 已知两人的翻前手牌时，选「翻前全下」，各输入两张牌。结果按模拟发完五张公共牌估算。「交换手牌」可切换观察方。
- 已知公共牌时，选「翻后范围」。默认给所有合法对手手牌相同权重。三张公共牌时模拟后续发牌；四张时穷举河牌；五张时直接摊牌。
- 「独赢率」只计自己获胜的机会。「底池权益」把平局按半个底池计入。例如公共牌已经组成皇家同花顺时，双方打平，自己的权益为 50%。
- 计算中可点「取消计算」，改好输入后重新开始。Android 切到后台会停止活动计算，返回后可重算。需要下次打开时恢复结果，请先点「保存局面」。

## 研究河牌下注

1. 打开河牌策略页，在「载入基准」选择「小范围 · 等权」或「小范围 · 非等权」。OOP 先行动，IP 后行动。
2. 首次可直接点「开始牌局求解」。自定义时，选好五张公共牌，在「编辑双方范围与下注尺度」中设定手牌、权重和筹码金额。例如首注填 `50`、加注填 `50:100`，表示面对 50 的首注可以加到总额 100。
3. 在「求解状态」查看「模型误差（占起始底池）」。目标为 0.1% 或更低；若先耗尽预算，结合实际误差阅读结果。要分次运行，可点「暂停并保存」，再从检查点继续。
4. 在「已经发生的行动」选择路径，再选择行动方的两张牌。先读底池和要补的筹码。例如底池原有 100，对手下注 50 后轮到你，跟注 50 后底池共 200，打平需要 25% 权益。实际权益等于独赢概率加一半的平局概率。
5. 在「不同打法差多少」对照每个动作的采用频率与平均收益差。模型也可能混用两种打法。在「对手拿什么牌继续」切换下注金额，点开跟注或加注，能看到更强、打平及更弱的具体手牌。每组的百分比以作出该回应的对手牌为分母。
6. 「行动方的整体范围」综合该位置的所有可达手牌。展开「详细频率与行动 EV」可以核对原始数值。修改局面后需重新求解，误差达标后才会显示正式解读。
